# 🎵 Spotify Artist Streaming Analytics

An end-to-end **Data Analytics / Business Intelligence project** analyzing Spotify artist streaming performance across artists, genres, countries, artist types, gender, and collaboration patterns.

The project follows a practical analytics workflow:

**Raw Data → Python/Pandas Cleaning → MySQL → SQL Analysis → Business Insights → Dashboard Design**

---

## 📌 Project Overview

This project analyzes a dataset containing **500 Spotify artists** across:

- 🌍 43 countries
- 🎵 23 genres
- 🗣️ 11 primary languages
- 📅 Debut years from 1939 to 2023
- 📊 14 analytical fields

The objective is to understand what drives streaming performance and identify meaningful patterns across artists, genres, countries, artist types, and collaboration behavior.

---

## 🎯 Business Objective

The main objective is to transform raw Spotify streaming data into meaningful business insights that can support:

- Artist development
- A&R decision-making
- Regional marketing
- Genre investment
- Collaboration strategy
- Streaming performance analysis
